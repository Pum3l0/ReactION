## Что это

**ReactION** — браузерная игра про химию. Игрок становится работником
химического производства, а рабочие задачи — это школьная программа:
немного сюжета, немного практики и много наглядности.

Проект состоит из **двух разделов**, между которыми переключаются прямо в меню:

| Раздел | Кто ты | Что там |
|---|---|---|
| **Смена** | рабочий химического цеха | сюжетные задачи от мастера: склад реактивов, лабораторные задания по программе, строение атома |
| **Лаборатория** | ученик / лаборант | свободный тренажёр опытов для школ без реактивов: полигон реакций, песочница атома |

Смена = история и контекст. Лаборатория = чистый тренажёр и эксперименты.

## Возможности

- 🧪 **3D-рабочий стол**: процедурная посуда (пробирки, стакан, колба), горелка,
  штатив — всё построено из геометрии Three.js, без внешних 3D-моделей.
- ⚗️ **Настоящие реакции**: движок по таблице растворимости выдаёт осадок,
  газ, смену цвета и работу индикаторов.
- 🔥 **Нагрев**, ⧗ **фильтрование осадка**, 🧲 **отделение стружки магнитом** —
  с наглядными следами на столе.
- 🧬 **Песочница атома**: пишешь электронную конфигурацию — игра на лету
  распознаёт элемент и строит 3D-атом.
- 📋 **Таблицы** Менделеева и растворимости доступны прямо в лаборатории.
- 📓 **Журнал опытов**: все выполненные реакции с уравнениями.
- 📱 **Адаптив**: ПК, планшет и телефон (на телефоне — подсказка повернуть
  экран горизонтально).

## Стек

- **Vite** — сборка
- **Three.js** — 3D-сцены
- **GSAP** — анимации
- **Vanilla JS** — без фреймворков
- Вся графика 3D — процедурная; иконки локаций и логотип — SVG

## Запуск

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Структура

```
src/
  core/            ядро: рендерер, свет, экраны, состояние игры
    chem/          движок реакций и состояние стола
    three/lab/     процедурная геометрия, эффекты, сцена лаборатории
  data/            данные: реакции, задания смены, электронные конфигурации
  scenes/          3D-модели (атом)
  screens/         экраны: меню, карта, склад, орбитарий, лаборатория, песочница атома
  styles/          стили (M3 Expressive, тёплая палитра «масло/чернила»)
  ui/              интерфейсные компоненты: переключатель режимов, панель реактивов
```
